────────────────────────────────────────────────────────────────────────────────
PROJECT OVERVIEW
────────────────────────────────────────────────────────────────────────────────

Gitpath turns any public GitHub repository into an interactive learning
course — structured lessons, quizzes, concept maps, an AI tutor, and a
gamification system (XP, levels, streaks, leaderboard).

Stack: Next.js 15 (App Router) · Prisma ORM · PostgreSQL (Supabase) · NextAuth v5
       OpenAI-compatible AI (Gemini / OpenRouter / Vast.ai / Ollama)

Data flow:
  User pastes GitHub URL
    → API clones the repo (simple-git)
    → Static analysis maps files/imports/exports (ts-morph, web-tree-sitter)
    → ONE AI call generates the full course JSON
    → Course stored in PostgreSQL forever (never re-generated)
    → All learners read from the cached DB record

ROOT FILES
────────────────────────────────────────────────────────────────────────────────

.env.example            Template for all environment variables (copy to .env.local).
                        Includes Supabase DB URLs, auth secrets, admin password,
                        AI provider options, and observability keys.

middleware.ts           Edge-safe request guard. Runs on every request BEFORE pages.
                        - Protects /dashboard, /learn, /profile, /explore, /achievements
                          by checking for the NextAuth session cookie.
                        - Protects /admin/dashboard by checking for the admin
                          HMAC token cookie (gp_admin_token).
                        - Does NOT call Prisma/auth() here — edge runtime can't use Node.

next.config.mjs         Next.js configuration. Security headers (CSP, HSTS, etc.),
                        image domains, and environment variable forwarding.

tailwind.config.ts      Tailwind CSS configuration. Adds custom brand colours
                        (brand-indigo, brand-violet), animation utilities,
                        and the "accent-gradient" class used throughout the UI.

tsconfig.json           TypeScript config. Sets "@/*" path alias to project root.

components.json         shadcn/ui component config. Controls where generated
                        components land and which CSS variable names are used.

turbo.json              Turborepo pipeline config (used when running the monorepo
                        with pnpm workspaces via pnpm-workspace.yaml).

docker-compose.yml      Defines a postgres:16-alpine service for production deploy
                        (e.g. AWS Lightsail). Same credentials as the Supabase URL.

understand.txt          ← This file. Explains the project to developers and AI tools.

prisma/
────────────────────────────────────────────────────────────────────────────────

schema.prisma           The database schema. One source of truth for all tables.
                        Key models:
                          User          — learner accounts, XP, level, vibeScore
                          Account       — OAuth provider links (NextAuth)
                          Session       — DB-backed NextAuth sessions
                          Repository    — a cloned GitHub repo (owner-scoped)
                          RepositoryGraph — static analysis result (JSON)
                          Course        — the AI-generated course for a repo
                          Module        — a chapter within a course
                          Lesson        — a single lesson (explanation + code + quiz)
                          Quiz          — quiz question attached to a lesson
                          QuizAttempt   — records each time a user answers a quiz
                          UserProgress  — per-user per-lesson completion state + XP
                          Concept       — a named coding concept (e.g. "react-context")
                          ConceptMastery — user's mastery level (0-3) per concept
                          Enrollment    — user enrolled in a course
                          Badge / UserBadge — achievement badges
                          TutorSession / TutorMessage — AI tutor chat history
                          AIJob         — tracks async AI generation jobs

seed-leaderboard.mjs    Seeds 10 fake users so the leaderboard is pre-populated.
                        Fake users have isFakeUser=true and XP from 30 to 290.
                        Run once with: node prisma/seed-leaderboard.mjs

seed.ts                 Prisma seed file for concepts and initial data.

lib/
────────────────────────────────────────────────────────────────────────────────

lib/auth.ts             NextAuth v5 configuration. Defines GitHub OAuth provider,
                        uses Prisma adapter for DB-backed sessions. Exports auth(),
                        signIn(), signOut() used throughout server components.

lib/db/index.ts         Exports a singleton Prisma client (db). Prevents multiple
                        client instances during Next.js hot-reload in development.

lib/crypto/encryption.ts  AES-256-GCM encrypt/decrypt for GitHub OAuth tokens
                          stored in the DB. Tokens are encrypted at rest.

lib/logger.ts           Pino logger with Better Stack log drain integration.
                        Logs are structured JSON in production.

lib/turnstile.ts        Cloudflare Turnstile CAPTCHA verification. Called on
                        the repository import form. Returns true immediately when
                        TURNSTILE_SECRET_KEY is not configured (dev mode).

lib/admin/auth.ts       Admin-only authentication utilities.
                        - ADMIN_EMAILS: hard-coded list of authorised admin emails
                        - verifyAdminCredentials(): checks email allowlist +
                          timing-safe password comparison against ADMIN_PASSWORD env
                        - createAdminToken(): creates a signed HMAC-SHA256 token
                        - verifyAdminToken(): verifies signature + expiry
                        - getAdminSession(): reads and verifies the admin cookie

lib/ai/client.ts        OpenAI SDK client configured to call any OpenAI-compatible
                        endpoint (Gemini, OpenRouter, Vast.ai, Ollama). The URL,
                        model, and key come from AI_BASE_URL / AI_MODEL / AI_API_KEY.
                        Also contains step-by-step Vast.ai GPU setup instructions
                        as comments at the top of the file.

lib/ai/generator.ts     The main course generation function. Takes a repository
                        analysis result and calls the AI once to produce a full
                        course JSON (modules + lessons + quizzes). Sanitises output
                        and saves everything to the database in one transaction.

lib/ai/prompts.ts       System prompts and response parsers for the AI. Includes
                        parseJSONFromResponse() which extracts valid JSON from the
                        AI's output even if it includes markdown fences or trailing
                        commas.

lib/analyzer/index.ts   Orchestrates the static analysis pipeline:
                          1. Lists all source files in the cloned repo
                          2. Extracts imports/exports via ts-morph
                          3. Detects frameworks, package manager, languages
                          4. Builds a RepositoryGraph (stored as JSON in the DB)

lib/pipeline/inline.ts  Runs the full clone→analyse→generate pipeline in-process
                        (no Redis/BullMQ required). Used when PIPELINE_MODE=inline.
                        Idempotent: skips steps already completed.

lib/queue/              BullMQ queue definition and worker for production use.
                        The worker processes generation jobs asynchronously so
                        the web server stays responsive.

lib/utils/cn.ts         Tiny utility: merges Tailwind class names with clsx + tailwind-merge.
lib/utils/xp.ts         XP and level calculation functions:
                          levelFromXp(xp)         — level 1-100 from raw XP
                          xpToReachLevel(n)        — total XP needed to reach level n
                          xpNeededForLevel(n)      — XP gap between level n and n+1
                          xpProgressInLevel(xp, l) — current/needed/pct for the progress bar
                          normaliseVibe(raw)        — maps 0-∞ raw vibe to 0-100 display

lib/types/              TypeScript interfaces for AI-generated course structures,
                        repository analysis results, and shared domain types.

lib/validators/         Zod schemas for validating API request bodies and AI output.

app/api/ — API routes
────────────────────────────────────────────────────────────────────────────────

app/api/auth/[...nextauth]/route.ts   NextAuth handler. Handles GitHub OAuth
                                      callbacks and session management.

app/api/repositories/route.ts        POST — imports a new GitHub repo.
                                      Clones, analyses, kicks off course generation.
                                      Scoped to session.user.id (repos are private).

app/api/progress/quiz-answer/route.ts POST — records a quiz answer.
                                      Awards XP (15 correct / 5 wrong), increments
                                      vibeScore, updates ConceptMastery level.

app/api/progress/complete-lesson/route.ts  POST — marks a lesson as completed.
                                           Awards lesson XP, bumps vibeScore +50,
                                           upserts ConceptMastery at level 1 for
                                           all concepts in the lesson. Idempotent.

app/api/admin/auth/route.ts           POST — admin login (sets gp_admin_token cookie).
                                      DELETE — admin logout (clears the cookie).

app/api/admin/stats/route.ts          GET — returns aggregate platform stats for
                                      the admin dashboard. Protected by admin cookie.
                                      Returns: user counts, lesson completions,
                                      quiz accuracy, XP aggregates, top users,
                                      daily chart data. NO sensitive fields.

app/api/dev-login/route.ts            GET — development-only shortcut login.
                                      Disabled in production (NODE_ENV check).

app/api/health/route.ts               GET — uptime check endpoint for Better Stack.
                                      Returns { status: "ok", db: "connected" }.

AI COST ESTIMATE — OpenRouter vs Vast.ai
────────────────────────────────────────────────────────────────────────────────

Token usage per repository:
  Small repo  (<10 files, e.g. a utility library):
    Input:  3,000–8,000 tokens  (repo content + system prompt)
    Output: 5,000–12,000 tokens (course JSON: 5–7 modules, 15–21 lessons)
    Total:  ~8,000–20,000 tokens

  Medium repo (10–50 files, typical npm package):
    Input:  10,000–30,000 tokens
    Output: 8,000–20,000 tokens
    Total:  ~18,000–50,000 tokens

  Large repo  (50+ files, e.g. a full Next.js app):
    Input:  30,000–80,000 tokens
    Output: 12,000–30,000 tokens
    Total:  ~42,000–110,000 tokens

OPTION A — OpenRouter (RECOMMENDED for starting out)
  Model: google/gemini-2.5-flash
    Input:  $0.075/MTok    Output: $0.30/MTok
    Cost per small repo:   ~$0.0006–0.004
    Cost per medium repo:  ~$0.003–0.012
    Cost per large repo:   ~$0.009–0.030
  Model: deepseek/deepseek-v3
    Input:  $0.14/MTok     Output: $0.28/MTok
    Cost per small repo:   ~$0.001–0.004
    Cost per medium repo:  ~$0.005–0.020

  ✅ No upfront cost — pay as you go
  ✅ No GPU setup or maintenance
  ✅ Switch models by changing one env var
  ✅ Gemini 2.5 Flash is excellent at structured JSON (course generation)
  ✅ Google AI Studio gives 1,000,000 free tokens/day for development

OPTION B — Vast.ai GPU (better at scale)
  Hardware: RTX 4090 (2x) @ ~$0.50–$0.80/hr
  Model: Llama 3.3 70B Q4_K_M (runs on ~40 GB VRAM)
  Generation speed: 30–120 seconds per repo
  Cost per repo: ~$0.004–0.027

  ✅ Cheapest per-token at high volume (>100 repos/day)
  ✅ No third-party data sharing (model runs on YOUR rented GPU)
  ❌ Setup time: 20–30 minutes per session
  ❌ GPU availability can vary
  ❌ Quality may be lower than Gemini for structured JSON

VERDICT:
  Start → OpenRouter (google/gemini-2.5-flash or gemini via AI Studio free tier)
  Scale → Switch to Vast.ai when processing >50 repos/day AND quality is acceptable

  The AI_BASE_URL / AI_API_KEY / AI_MODEL env vars make switching providers
  a one-line change in .env.local — no code changes needed.

DEVELOPMENT WORKFLOW
────────────────────────────────────────────────────────────────────────────────

1. Copy .env.example to .env.local and fill in your values.

2. Start the embedded local PostgreSQL:
     pnpm db:local
   (Uses embedded-postgres — no Docker or system Postgres needed)

3. Apply the schema to the local DB:
     DATABASE_URL="postgresql://postgres:postgres@localhost:5432/gitpath" \
     DIRECT_URL="postgresql://postgres:postgres@localhost:5432/gitpath" \
     pnpm prisma db push

4. (Optional) Seed the leaderboard with fake users:
     node prisma/seed-leaderboard.mjs

5. Start the dev server:
     pnpm dev

6. Log in without GitHub OAuth:
     Visit http://localhost:3000/api/dev-login (dev only)

7. Visit the admin panel:
     http://localhost:3000/admin/login
     Email:    balajiilabs@gmail.com  OR  dharoonbalajiie@gmail.com
     Password: set in ADMIN_PASSWORD env var

IMPORTANT: After running "prisma db push", always RESTART the dev server.
Next.js hot-reload does NOT reload the Prisma client across schema changes.

SUPABASE SETUP GUIDE
────────────────────────────────────────────────────────────────────────────────

1. Create a free Supabase project at https://supabase.com
2. Go to Settings → Database → Connection Pooling → Copy "Transaction" mode URL
   → Paste as DATABASE_URL in .env.local
3. Go to Settings → Database → Connection string → URI → Copy direct URL
   → Paste as DIRECT_URL in .env.local
4. Run: pnpm prisma db push
   (This creates all tables in your Supabase project)
5. Run: node prisma/seed-leaderboard.mjs
   (This populates the leaderboard with fake users)
6. That's it — the app is now backed by Supabase PostgreSQL.

To switch to Amazon RDS later:
  Change DATABASE_URL and DIRECT_URL to your RDS connection strings.
  Nothing else changes — Prisma, the schema, and all code stay identical.

SECURITY NOTES
────────────────────────────────────────────────────────────────────────────────

- GitHub OAuth tokens are encrypted with AES-256-GCM before storage (lib/crypto/)
- Admin sessions use HMAC-SHA256 signed tokens with expiry (24h)
- Admin password comparison uses crypto.timingSafeEqual (prevents timing attacks)
- Repository queries are always scoped to session.user.id (no cross-user data leak)
- Admin panel is robots=noindex and behind a separate auth system
- The admin panel NEVER returns GitHub tokens, passwords, or session secrets
- httpOnly cookies prevent JavaScript from reading auth tokens (XSS protection)
- SameSite=Lax on cookies prevents CSRF attacks
